# ValkyOS manifest (retired)

This repository is no longer used. It was the local manifest that added
ValkyOS on top of the LineageOS manifest.

ValkyOS now has its own manifest:

```
repo init -u https://github.com/ValkyOS/android -b 17 --git-lfs
```

Build guide, features and credits: https://github.com/ValkyOS/android

Motorola Edge 50 Pro (eqe) device repositories: https://github.com/dvy-jp/local_manifests
(branch `valkyos-17`).
